# MXSIG IVEA

Este repositorio contiene los archivos de configuración personalizados de la implementación para IVEA de [MXSIG](https://git.inegi.org.mx/mxsig/mxsig).

## Contenido

- `ivea/`: archivos de las capas de MapServer.
- `scripts/`: definiciones de las capas y script para generar los archivos de MapServer.
- `mapa/`: archivos personalizados del cliente web.
- `deploy.sh`: script que sustituye todos los archivos correspondientes dentro de MXSIG.

**Importante:** al ejecutar `deploy.sh`, se reemplazan los archivos existentes dentro de MXSIG.
